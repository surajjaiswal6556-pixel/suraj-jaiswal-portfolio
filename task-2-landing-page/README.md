# Task 2 — Responsive Landing Page

A responsive landing page concept built for the CodeOrbit Tech Web Development internship.

## Sections
- Header with navigation
- Hero section and primary call to action
- Three feature cards
- Three-step approach section
- Contact call to action
- Footer

## Technologies
- HTML5
- CSS3 (Flexbox, Grid, media queries, custom properties)
- Vanilla JavaScript (mobile navigation)

## Run locally
Open `index.html` in a browser, or open this folder in VS Code and use Live Server. No package installation or build step is needed.
