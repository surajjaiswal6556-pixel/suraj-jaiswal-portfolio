# Suraj Jaiswal — Personal Portfolio

A responsive personal portfolio website built for the CodeOrbit Tech Web Development internship project.

## Features
- About Me, Skills, Projects and Contact sections
- Responsive layout for desktop, tablet and mobile
- Mobile navigation menu with accessible state attributes
- Semantic HTML and CSS custom properties
- Small JavaScript enhancements for navigation and current year
- No frameworks or build tools required

## Technologies
- HTML5
- CSS3 (Flexbox, Grid, media queries)
- Vanilla JavaScript

## Run locally
1. Download or clone this repository.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Before publishing
1. Replace `your.email@example.com` in `index.html` with your real email address.
2. Replace the GitHub and LinkedIn profile links with your own profile URLs.
3. Add links and screenshots for additional projects only after completing them.
4. Review all personal details and test the page on desktop and mobile.

## Project purpose
This project demonstrates the fundamentals requested for a personal portfolio: About Me, Skills, Projects and Contact, using HTML, CSS and basic JavaScript with responsive design.
