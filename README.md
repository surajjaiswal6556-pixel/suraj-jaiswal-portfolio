# Suraj Jaiswal — Personal Portfolio

A responsive personal portfolio website created for the CodeOrbit Tech Web Development internship, Project 1.

## Live website

[View my portfolio](https://surajjaiswal6556-pixel.github.io/suraj-jaiswal-portfolio/)

## Project overview

This website introduces me, presents my current front-end skills, showcases my portfolio project, and provides contact information. It is built with HTML, CSS, and vanilla JavaScript.

## Sections

- **Home:** Short introduction and links to the main sections
- **About Me:** My learning journey and goals
- **Skills:** HTML5, CSS3, and JavaScript
- **Projects:** Personal Portfolio Website
- **Contact:** Email and social profile links

## Technologies used

- HTML5
- CSS3 — Flexbox, Grid, responsive media queries, and custom properties
- Vanilla JavaScript — navigation interactions and small page enhancements

## Run locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.

No framework, package installation, or build command is required.
